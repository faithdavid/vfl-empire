CORE QUESTION

Do we need data analysis?

Yes — but mostly practical Exploratory Data Analysis (EDA), not advanced data science.

EDA is simply the first deep look at your data: understanding patterns, relationships, and distributions using grouping, counting, binning, and visualization.

This project has already proven that this style of work delivers real value:

  • • The 100% "Odds DNA" clusters (exact GG + O2.5 combinations with perfect historical records) were found via binning + grouping + counting on the aligned dataset.
  • • The macro heatmaps that revealed "Hot Zones" and "Cold Zones" came from pandas + seaborn visualization.
  • • The 62% structural ceiling discovery and the realization that the engine also balances bookmaker liability came from careful historical backtesting + aggregation.

Data scientists often spend 70-80% of their time on exactly this kind of exploration. You don't need to become a data scientist — you need to become good at asking questions of the data using these tools as a very fast calculator + visualizer.

Key insight from research: The biggest breakthroughs in this repo so far used pandas groupby + pd.cut binning + simple percentage calculations on historical results + pre-match odds. This is accessible EDA.
THE ACTUAL STACK IN USE

Python Libraries — One by One

What each library is, what you actually get from it, and how it shows up in the VFL work.

CORE

pandas

The #1 tool used in this project so far

What it is (plain English)

A powerful Python library for working with tabular data — think "Excel or Google Sheets on steroids, but in code." It uses DataFrames (tables) and Series (columns).

What you get from it
  • • Load CSV, SQL results, JSON into clean tables
  • • Filter, sort, create new columns (win flags, bins)
  • • Group data and calculate rates inside groups
  • • Bin continuous numbers (odds) into categories
How it is used in VFL Empire
df['Home_Win'] = (df['home_goals'] > df['away_goals']).astype(int)
df['gg_category'] = pd.cut(df['gg'], bins=..., labels=...)

stats = df.groupby('gg_category').agg(
  Matches=('home_team', 'count'),
  Home_Win_Pct=('Home_Win', 'mean')
)

This exact pattern (from analyze_all_odds_categories.py) is how the 100% clusters and hot/cold zones were discovered.

FOUNDATION

numpy

NumPy is the engine for fast numerical computing in Python. It provides high-performance arrays and math functions. Pandas is built directly on top of NumPy.

What you get: Speed for large numbers, easy ranges for binning (np.arange), mathematical operations.
In this project you mostly see:
import numpy as np
bins = np.arange(1.30, 2.50, 0.05)
(used inside pd.cut for the odds categories)
DATA PIPE

psycopg2

The official adapter that lets Python talk to a PostgreSQL database (your vfl_empire DB).

What you get
Connect → run SQL → pull fresh rows into a pandas DataFrame for analysis.
In this project
conn = psycopg2.connect(...)
df = pd.read_sql_query(sql, conn)
Used to query vfl_fixture_aligned + vfl_odds_v2 when the CSV snapshot is stale.
SEE THE PATTERNS

matplotlib + seaborn

matplotlib is the base plotting library — extremely flexible but can require more code.

seaborn sits on top of matplotlib and is optimized for statistical plots with pandas. Much nicer defaults and far less code for heatmaps, distributions, and grouped stats.

Project usage
The "Pandas Visualization" phase in the master progress log (hot zones / cold zones) and the scatter plots of 100% clusters were made with these. Humans spot the gradients much better in pictures than in tables of percentages.
NEXT LAYER

scikit-learn (Decision Trees)

scikit-learn is the main machine learning library in Python. DecisionTreeClassifier learns simple "if feature X > value then..." rules directly from your data to predict outcomes.

Project plan (from master progress log Phase 5):
Feed the full aligned matrix (teams + matchday + odds combinations) into a decision tree so it automatically finds high-volume profitable branches instead of manual filtering.
This is further along the learning curve than pandas EDA. The current strongest signals (100% clusters) were found with grouping/binning before heavy ML.
